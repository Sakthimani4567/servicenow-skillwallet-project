# 🧠 ServiceNow SkillWallet Project

A centralized platform to track, validate, and showcase employee skills within ServiceNow.

### 🚀 Project Overview
ServiceNow SkillWallet helps organizations manage skill gaps, upskilling journeys, and internal talent mobility. Employees can add skills, get them validated by managers, and earn digital badges.

### ✨ Key Features
- **Skill Profile Management** - Employees can add/manage their technical & soft skills
- **Manager Validation Workflow** - Approval process for skill verification
- **Digital Badges & Certificates** - Auto-generated wallet for validated skills
- **Skill Gap Analysis** - Dashboard for managers to identify team gaps
- **Integration Ready** - Connects with Learning Management & HR modules

### 🛠️ Tech Stack
- **Platform:** ServiceNow (Istanbul / Yokohama)
- **Modules:** Custom App, Flow Designer, Scripted REST APIs
- **Frontend:** Service Portal, UI Builder
- **Backend:** Business Rules, Script Includes, Glide API

### 📂 Tables Used
- `x_sakthi_skillwallet_skills` - Master skill list
- `x_sakthi_skillwallet_employee_skills` - Employee skill mapping
- `x_sakthi_skillwallet_validations` - Validation workflow

### ⚙️ How to Install
1. Clone this repo
2. Import Update Set from `/update-sets` folder to your ServiceNow PDI
3. Assign roles `x_sakthi_skillwallet.user` and `x_sakthi_skillwallet.manager`
4. Open Service Portal -> SkillWallet
